## Adaptações em relação ao prompt original

- `summary` → `content`: o campo `summary` não existe no banco; o ETL `enrich_topics_llm.py`
  grava o resumo didático em `content` (UPDATE topics SET content = ...).
- `subject` derivado de `law_code` em runtime: não é coluna no banco; `LAW_CODE_TO_SUBJECT`
  mantém o mesmo mapeamento do ETL.
- `chips: []` removido do retorno KB: `chips` não faz parte de `TutorResponse` — é adicionado
  pelo controller via `{ ...response, chips }`.
- Campo `mode: req.mode` adicionado no retorno KB: obrigatório pelo schema `TutorResponseSchema`.
