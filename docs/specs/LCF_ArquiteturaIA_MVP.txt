CREATE INDEX idx_articles_fts ON legal_articles USING gin(content_tsv);

-- Trigger: mantém content_tsv sincronizado com content

CREATE TRIGGER tsvector_upd BEFORE INSERT OR UPDATE ON legal_articles

FOR EACH ROW EXECUTE FUNCTION

tsvector_update_trigger(content_tsv, 'pg_catalog.portuguese', content);

Storage estimado: 50k artigos (corpus OAB) x ~500 bytes = ~25 MB. Dentro do free tier Supabase (500 MB). Embeddings (v1.1): adiciona ~650 MB — gatilho para upgrade Supabase Pro ($25/mes).

2.2 ETL — Pipeline de Ingestao
Download do XML LexML para os 9 diplomas prioritarios OAB: CF, CC, CP, CLT, CPC, CPP, CTN, CDC, Estatuto da OAB.
Parser XML -> JSON estruturado respeitando hierarquia: artigo -> paragrafo -> inciso -> alinea. Preservar numeracao exata.
Importacao em lote via Prisma. O trigger gera content_tsv automaticamente.
Validacao: contagem de artigos importados vs. fonte + spot-check manual em 20 artigos por diploma.
(v1.1) Embeddings em batch via text-embedding-3-small. Custo one-time: ~$3 para 50k artigos.
Estimativa: 3-5 dias de engenharia, incluindo validacao. Nao e bloqueador de timeline.

3. Grounded Generation via Tool Use
O mecanismo central de anti-alucinacao. Claude recebe duas tools e e instruido a nunca citar um artigo sem antes ter chamado lookup_article. Se o artigo nao for encontrado no banco, Claude declara a limitacao ao usuario — nao fabrica a referencia.

DECISAO: Diferente de prompt engineering, este e um controle arquitetural: Claude fisicamente nao tem como retornar uma citacao verificada sem que o artigo exista no banco. O risco de alucinacao em citacoes especificas passa de probabilistico para impossivel.

3.2 Handler das Tools — citation.service.ts
async function handleToolCall(tc: ToolCall): Promise<ToolResult> {

if (tc.name === "lookup_article") {

const { law_code, article, paragraph, inciso } = tc.input;

const row = await db.legal_articles.findFirst({

where: { law_code, article_number: article, paragraph, inciso }

});

if (!row) return {

content: "ARTIGO NAO ENCONTRADO. Nao cite este artigo.",

is_error: false

};

return { content: JSON.stringify({

full_reference: row.full_reference,

content: row.content,

law_name: row.law_name

})};

}

if (tc.name === "search_legislation") {

const { query, law_code, limit = 5 } = tc.input;

const rows = await db.$queryRaw`

SELECT full_reference, content, law_name,

ts_rank(content_tsv, plainto_tsquery('portuguese', ${query})) AS rank

FROM legal_articles

WHERE content_tsv @@ plainto_tsquery('portuguese', ${query})

${law_code ? Prisma.sql`AND law_code = ${law_code}` : Prisma.empty}

ORDER BY rank DESC LIMIT ${limit}

`;

return { content: JSON.stringify(rows) };

}

}

5.4 Loop Agentico — tutor.service.ts
async function chat(req: TutorRequest): Promise<TutorResponse> {

const adapter = llmRouter.select(req);

const history = await sessionService.getHistory(req.sessionId);

const system = contextService.build(req);

const messages = [...history, { role:"user", content:req.message }];

// Loop: Claude chama tools ate ter resposta final

let res = await adapter.complete({ systemPrompt:system, messages, tools });

while (res.stop_reason === "tool_use") {

const results = await Promise.all(

res.tool_calls.map(tc => citationService.handle(tc))

);

messages.push({ role:"assistant", content:res.content });

messages.push({ role:"user", content:results });

res = await adapter.complete({ systemPrompt:system, messages, tools });

}

await sessionService.append(req.sessionId, messages);

return citationService.parse(res.content);

}

7. System Prompt — Camadas de Controle
O system prompt opera em cinco camadas, sendo a primeira a mais critica em termos de anti-alucinacao.

Camada

Instrucao

Efeito

1 — Tool Use obrigatorio

Nunca cite um artigo sem antes chamar lookup_article. Se o artigo nao for encontrado, declare a limitacao.

Impossibilita citacao fabricada

2 — Identidade e escopo

Voce e o Tutor IA do LCF, especialista em Direito Brasileiro e OAB. Nao responda fora do dominio juridico-educacional.

Delimita o perimetro de atuacao

3 — Registro didatico

Responda como professor explicando para aluno de graduacao. Use exemplos concretos. Evite jargao excessivo.

Garante linguagem adequada ao publico

4 — Output estruturado

Retorne sempre JSON valido seguindo o schema TutorResponseSchema.

Força tipagem e campos de certeza

5 — Sinalizacao de limite

Quando nao tiver certeza suficiente, declare no campo disclaimer e defina confidence: low.

Transparencia ativa com o usuario
